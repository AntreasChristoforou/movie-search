# Movie Search

A web app that searches the OMDb API and displays movie results.

## Built with
- HTML, CSS, vanilla JavaScript
- OMDb API, fetch + async/await

## What I learned
Working with promises and async/await, handling API errors,
and rendering data to the DOM dynamically.

## Note
The API key is visible in the client-side code, which is a known
limitation of front-end-only projects. The proper solution is a
backend proxy holding the key — planned for a future version.
